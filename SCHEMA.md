# Data Models & Schema Reference
## AUTONOMI AGENTIC ILMIAH (AAI) v1.1.0

---

## 1. Overview & Architectural Foundations

AAI schemas are built with **Pydantic 2.x**. Every data entity adheres to strict validation rules, immutability of audit fields, and structured history tracking. All records subclass either `SchemaModel` or `BaseRecord` (`src/schemas/base.py`).

### 1.1 Base Classes & Invariants

```
               SchemaModel
         (Pydantic BaseModel with
      extra="forbid", assignment check)
                    │
                    ▼
               BaseRecord
     (Adds stable ID, schema_version,
       timestamps, history, errors)
         │           │           │
         ▼           ▼           ▼
      Source     Evidence      Claim
         │           │           │
    (v1.1 fields) (v1.1 fields) (v1.1 fields)
```

- **`SchemaModel`**:
  Configured with `ConfigDict(extra="forbid", validate_assignment=True, populate_by_name=True, str_strip_whitespace=True)`. Arbitrary or unmodeled keys are rejected during initialization to prevent silent schema drift.
- **`BaseRecord`**:
  Adds foundational auditability fields:
  - `id: str`: Globally unique identifier with typed prefix (`src_`, `evd_`, `clm_`, `rev_item_`, etc.).
  - `schema_version: str`: Version indicator (`"1.0"` or `"1.1"`).
  - `created_at: datetime`: UTC creation timestamp.
  - `updated_at: datetime`: UTC modification timestamp (updated on `.touch()`).
  - `history: list[StateTransition]`: Immutable log of state transitions (from_state, to_state, reason, actor, timestamp).
  - `errors: list[ErrorInfo]`: Log of operational or validation issues encountered.

## 2. Versioning & Backward Compatibility (v1.0 → v1.1)

AAI follows a non-breaking forward-additive schema evolution model.

### 2.1 Compatibility Guarantees

1. **Default Value Infill**:
   When legacy v1.0 records (which lack v1.1 fields) are loaded from disk or API input:
   - `Evidence.evidence_type` defaults to `EvidenceType.NOT_SUPPORTED`.
   - `Evidence.reading_depth` defaults to `ReadingDepth.UNAVAILABLE`.
   - `Evidence` structured extraction fields default to `None`.
   - `Source.reading_depth` defaults to `ReadingDepth.UNAVAILABLE`.
   - `Source.retrieval_status` defaults to `RetrievalStatus.NOT_ATTEMPTED`.
   - `Source.publisher_verified` defaults to `False`.
   - `Source.index_status` defaults to `{}`.
2. **Acceptance of Schema Versions**:
   Deserialization accept records with `schema_version: "1.0"` or `"1.1"`.
3. **Selective Serialization**:
   Newly initialized records carry `schema_version: "1.1"`. Serialization via `model_dump()` omits fields that were not explicitly set when necessary to maintain clean, backward-compatible JSON payloads.

## 3. Evidence Schema Reference (`src/schemas/evidence.py`)

### 3.1 Enums

#### `EvidenceType(StrEnum)`
- `DIRECT`: Direct empirical observation of the claim phenomenon.
- `PARTIAL`: Empirical observation of related phenomenon or population.
- `THEORETICAL`: Conceptual framework, review, or deductive reasoning.
- `FUNCTIONAL_EQUIVALENT`: Analogous mechanism, proxy, or alternative platform.
- `BACKGROUND`: Contextual fact, macro statistic, or general setting.
- `CONTRADICTORY`: Empirical refutation or opposing correlation.
- `NOT_SUPPORTED`: Null finding, non-significant result, or uninformative data.

#### `ReadingDepth(StrEnum)`
- `FULL_TEXT`: Complete article/document read and parsed.
- `ABSTRACT_ONLY`: Title and abstract only.
- `METADATA_ONLY`: Bibliographic metadata only.
- `UNAVAILABLE`: Inaccessible or unread source.

#### `EvidenceRelationship(StrEnum)`
- `SUPPORTS`: Directly or positively supports the claim.
- `PARTIALLY_SUPPORTS`: Provides incomplete or partial support.
- `CONTRADICTS`: Rebuts or contradicts the claim.
- `IRRELEVANT`: Not applicable to the claim.

#### `EvidenceStrength(StrEnum)`
- `WEAK`: Anecdotal, small sample, or passing reference.
- `MODERATE`: Single study, standard sample size, or indirect measure.
- `STRONG`: Well-powered replication, authoritative primary research.
- `DEFINITIVE`: Systematic review, meta-analysis, or canonical definition.

#### `ExtractionMethod(StrEnum)`
- `VERBATIM_FULLTEXT`: Exact text copied from retrieved full text.
- `VERBATIM_ABSTRACT`: Exact text copied from abstract.
- `MODEL_PARAPHRASE`: Synthetic paraphrase generated by model.
- `TABULAR_VALUE`: Numeric value read from table/caption.
- `USER_PROVIDED`: Manually supplied by researcher.

### 3.2 Value Object: `EvidenceLocation`

```python
class EvidenceLocation(SchemaModel):
    page: int | None = Field(default=None, ge=1)
    page_label: str | None = None
    section: str | None = None
    paragraph: int | None = Field(default=None, ge=1)
    char_start: int | None = Field(default=None, ge=0)
    char_end: int | None = Field(default=None, ge=0)
    locator: str | None = None
```

- **Validation**: Ensures `char_end >= char_start` if both are provided.
- **Precision Property**: `is_precise` returns `True` only if at least one of `page`, `page_label`, `section`, or `locator` is populated.

### 3.3 Main Model: `Evidence`

```python
class Evidence(BaseRecord):
    id_prefix: str = Field(default="evd", exclude=True, repr=False)
    schema_version: str = "1.1"

    claim_id: str
    source_id: str
    evidence_text: str = Field(min_length=1)
    location: EvidenceLocation = Field(default_factory=EvidenceLocation)
    relationship: EvidenceRelationship = EvidenceRelationship.SUPPORTS
    strength: EvidenceStrength = EvidenceStrength.MODERATE
    confidence: float = Field(default=0.0, ge=0.0, le=1.0)
    extraction_method: ExtractionMethod = ExtractionMethod.VERBATIM_FULLTEXT
    verbatim: bool = True
    quote_verified: bool = False
    extracted_by: str | None = None
    notes: str | None = None

    # --- Evidence Intelligence fields (v1.1) ---
    evidence_type: EvidenceType = EvidenceType.NOT_SUPPORTED
    reading_depth: ReadingDepth = ReadingDepth.UNAVAILABLE

    # Structured extraction fields (optional, omitted when None)
    normalized_finding: str | None = None
    population: str | None = None
    sample_size: str | None = None
    methodology: str | None = None
    variables: list[str] | None = None
    instruments: list[str] | None = None
    statistical_result: str | None = None
    limitations: str | None = None
```

### 3.4 Constraints & Model Validators
1. **Verbatim Paraphrase Guard**:
   If `extraction_method == ExtractionMethod.MODEL_PARAPHRASE`, `verbatim` is automatically set to `False`.
2. **Reading Depth Constraint**:
   If `reading_depth == ReadingDepth.ABSTRACT_ONLY` and `extraction_method == ExtractionMethod.VERBATIM_FULLTEXT`, model initialization raises `ValueError`.
3. **Compact Serialization**:
   Structured extraction fields with `None` values are omitted from JSON outputs.

## 4. Source Schema Reference (`src/schemas/source.py`)

### 4.1 Enums

#### `SourceState(StrEnum)`
`DISCOVERED` → `METADATA_VERIFIED` → `DOI_VERIFIED` → `PUBLISHER_VERIFIED` → `FULLTEXT_RETRIEVED` → `EVIDENCE_EXTRACTED` → `CLAIM_SUPPORTED` → `APPROVED`. Failure/review branches: `REJECTED`, `NEEDS_HUMAN_REVIEW`.

#### `RetrievalStatus(StrEnum)`
- `RETRIEVED`: Full document successfully fetched and cached.
- `PARTIAL`: Incomplete document, partial pages, or paywall excerpt.
- `FAILED`: Retrieval attempt failed.
- `NOT_ATTEMPTED`: Candidate source awaiting retrieval.

### 4.2 Main Model: `Source`

```python
class Source(BaseRecord):
    id_prefix: str = Field(default="src", exclude=True, repr=False)
    schema_version: str = "1.1"

    title: str
    authors: list[str] = Field(default_factory=list)
    year: int | None = None
    venue: str | None = None
    volume: int | str | None = None
    issue: int | str | None = None
    pages: str | None = None
    doi: str | None = None
    url: str | None = None
    abstract: str | None = None
    source_type: SourceType = SourceType.OTHER
    state: SourceState = SourceState.DISCOVERED
    verification_notes: list[str] = Field(default_factory=list)
    citation_count: int | None = None
    retrieval_path: str | None = None
    metadata: dict[str, Any] = Field(default_factory=dict)

    # --- Evidence Intelligence fields (v1.1) ---
    reading_depth: ReadingDepth = ReadingDepth.UNAVAILABLE
    retrieval_status: RetrievalStatus = RetrievalStatus.NOT_ATTEMPTED
    publisher_verified: bool = False
    index_status: dict[str, bool] = Field(default_factory=dict)
```

### 4.3 Methods & State Transition Guards
- **`transition_to(new_state, *, reason, actor)`**:
  Records an audit transition in `self.history`.
  - **Guard**: Raises `StateTransitionError` if attempting to enter `SourceState.FULLTEXT_RETRIEVED` while `retrieval_status == RetrievalStatus.NOT_ATTEMPTED`.
- **`update_reading_depth(new_depth, *, reason, actor)`**:
  Updates `reading_depth` and appends a transition entry to `self.history`.
- **`approve()` / `reject()` / `request_review()`**:
  High-level transitions for validation workflows.

## 5. Claim Schema Reference (`src/schemas/claim.py`)

### 5.1 Enums

#### `ClaimImportance(IntEnum)`
- `LOW = 1`: Incidental assertion.
- `MEDIUM = 2`: Standard supporting statement.
- `HIGH = 3`: Load-bearing scientific assertion (mandatory evidence).
- `CRITICAL = 4`: Central thesis with real-world or theoretical consequences.

#### `ClaimStatus(StrEnum)`
- `PROPOSED`: Drafted proposition without verified evidence.
- `INVESTIGATING`: Discovery/extraction underway.
- `SUPPORTED`: Validated by positive evidence meeting threshold.
- `PARTIALLY_SUPPORTED`: Partial warrants attached.
- `INSUFFICIENT_EVIDENCE`: Evidential warrants insufficient.
- `CONFLICTED`: Conflicting/contradictory evidence detected.
- `REFUTED`: Proven false by contradictory findings.
- `NEEDS_HUMAN_REVIEW`: Escalated to human coordinator.

### 5.2 Main Model: `Claim`

```python
class Claim(BaseRecord):
    id_prefix: str = Field(default="clm", exclude=True, repr=False)

    claim_text: str
    importance: ClaimImportance = ClaimImportance.MEDIUM
    status: ClaimStatus = ClaimStatus.PROPOSED
    support_level: SupportLevel = SupportLevel.NONE
    confidence: float = Field(default=0.0, ge=0.0, le=1.0)
    supporting_evidence: list[str] = Field(default_factory=list)
    contradicting_evidence: list[str] = Field(default_factory=list)
    supporting_sources: list[str] = Field(default_factory=list)
    required_source_count: int = 1
    evidence_required: bool | None = None
    qualifier: str | None = None
    semantic_review: SemanticReview | None = None
```

## 6. ProvenanceRecord Reference (`src/schemas/provenance_record.py`)

```python
class ProvenanceRecord(SchemaModel):
    source_id: str
    evidence_id: str
    claim_id: str
    reading_depth: ReadingDepth
    page: int | None = None
    section: str | None = None
    retrieved_at: datetime | None = None
    verified_at: datetime | None = None
    verification_method: str | None = None
    evidence_relation: EvidenceRelationship

    @field_serializer("retrieved_at", "verified_at")
    def _ser_timestamps(self, value: datetime | None) -> str | None:
        return value.isoformat() if value is not None else None
```

- Subclasses `SchemaModel` directly.
- Undetermined timestamps or locators are stored as `None`.
- Serializes timestamps to ISO 8601 strings.

## 8. Serialization & Storage Specifications

| Artifact | File Format | Storage Primitive | Failure Behavior |
| :--- | :--- | :--- | :--- |
| Sources Registry | `sources.json` | `write_json` (atomic) | Returns `[]` if file missing on load. |
| Evidence Registry | `evidence.jsonl` | `append_jsonl` | Returns `[]` if file missing on load. |
| Claims Registry | `claims.json` | `write_json` (atomic) | Returns `[]` if file missing on load. |
| Evidence Graph | `evidence_graph.json` | `save_evidence_graph` | Returns `{}` if file missing on load. |
| Provenance Trail | `provenance.jsonl` | `save_provenance_chain` | Returns `[]` if file missing on load. |
| Review Queue | `review_queue.json` | `ReviewQueue.save` | Returns empty `ReviewQueue()` if missing. |

All write operations enforce filesystem boundary checks (`src.core.storage.ensure_within`) to prevent directory traversal outside permitted project roots.
