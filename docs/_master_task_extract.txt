=== PARAGRAPHS ===
MASTER TASK SETIAP FASE
AUTONOMI AGENTIC ILMIAH
Roadmap Eksekusi, Keterangan Task, Fungsi, Output, dan Status
Tujuan dokumen: menjadi panduan sederhana agar setiap fase pengembangan memiliki pekerjaan yang jelas, fungsi yang mudah dipahami, dan hasil yang dapat diperiksa sebelum melanjutkan ke fase berikutnya.
Tujuan utama proyek: membangun AI agent penelitian akademik yang semakin mandiri, menggunakan referensi yang benar-benar ada, memverifikasi evidence sebelum menulis klaim, melakukan audit, dan menghasilkan dokumen akhir yang dapat dipertanggungjawabkan.
Status: SELESAI = sudah dibangun dan diuji; NEXT = fase berikutnya; RENCANA = belum dikerjakan.
Aturan wajib setiap fase: Architecture Review → Pre-Implementation Gate → Implementation Plan → Implementasi → Tests → Integration Test (jika relevan) → Import Check → Bootstrap → Architecture Audit → Dokumentasi → Report → STOP.
Catatan penting: Fase berikutnya hanya boleh dimulai setelah fase sebelumnya lolos acceptance criteria. Tujuan utama tetap kualitas dan keterlacakan ilmiah, bukan banyaknya fitur atau banyaknya kode.
